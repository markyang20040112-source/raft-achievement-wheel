> **核心檔案**：

> - `raft_achievements_104.json`：104 項全成就標準結構化資料庫。

## ⚖️ 比重（權重）計算模型

轉盤的核心機制為 **依據全球達成率動態分配轉中機率**，避免在遊戲初期抽中極度後期的地獄級成就。

### 1. 難度階梯與預設比重公式
| 難度等級 | Steam 全球達成率 | 預設比重 (Weight) | 遊戲階段定位 |
| :--- | :---: | :---: | :--- |
| 🟢 **極易 / 常見** | **≥ 60%** | **45 ～ 55** | 新手入門、基礎生存（如活過第1天、釣魚、初級淨化器、生火） |
| 🟡 **普通 / 中等** | **30% ～ 59%** | **30 ～ 44** | 中期擴張、主線中繼點（如瓦薩加坦、熊島、大篷車鎮、中級獵人） |
| 🟠 **困難 / 進階** | **10% ～ 29%** | **15 ～ 29** | 首領擊殺、全角色解鎖、終章烏托邦、金屬探測器、研究桌全收集 |
| 💀 **極限 / 稀有** | **< 10%** | **5 ～ 14** | 後期極限刷刷樂（生存365天、50隻尖嘯者/鮟鱇魚、全提基圖騰） |

### 2. 支援四大運算模式 (即時切換)
1. 🌟 **Steam全球達成率比重 (推薦模式)**：高達成率成就先被抽中，隨遊戲進程逐步遞進。
2. ⚖️ **均等機率模式 (1:1)**：所有候選成就權重皆為 10，完全平分中獎機率。
3. 💀 **反向地獄挑戰模式**：權重改為 `Math.round((100 - 全球達成率) * 0.8)`，達成率最低的稀有成就最高機率被抽出。
4. ✏️ **自訂權重模式**：可在卡片點擊 ✏️ 任意編輯自選數值。
